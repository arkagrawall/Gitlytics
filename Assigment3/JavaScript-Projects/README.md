# JavaScript Practical Lab Projects — Assignment 3

This directory contains 5 modular frontend JavaScript applications built using semantic HTML5, modern CSS3 styling, and ES6+ DOM manipulation techniques.

---

## 📂 Projects Directory

1. **[1-bmi-calculator](./1-bmi-calculator)**: Interactive Body Mass Index health calculator with metric height/weight inputs and classified weight ranges.
2. **[2-signup-validation](./2-signup-validation)**: Client-side form validation verifying name length, email syntax, password security rules, and password match confirmation.
3. **[3-theme-changer](./3-theme-changer)**: Dynamic UI theme switcher supporting light, dark, and emerald color schemes via CSS custom properties and `data-theme` attributes.
4. **[4-digital-clock](./4-digital-clock)**: Real-time digital clock rendering 12/24-hour time and full localized calendar dates using `setInterval()` and `Date` objects.
5. **[5-todo-list](./5-todo-list)**: Task management tool supporting dynamic item creation, task completion toggling, deletion, and empty state feedback.
